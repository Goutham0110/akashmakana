Direction

Register: brand. The design is the product.

Colour strategy: drenched near-black with a single ember accent. All colour comes from photography; the UI stays black, bone-white and one orange. No purple-and-cyan nightlife cliché, no gradient text, no glass.

Aesthetic lane: gig-poster / flyposter. Heavy compressed display type, square corners, full-bleed imagery, editorial captions. Not editorial-serif, not SaaS-minimal.

Motion: restrained. One settle-in on scroll, hover state changes, lightbox open/close, one hero marquee. Everything has a reduced-motion path and works without JS.

Contrast ratios are against #08080a, all above WCAG AA for body text. Body copy uses ink or ink-muted. Ink-faint is reserved for labels, captions and large display numbers. Text on the ember button uses #0a0602 (7.1:1).

Type

Display: Anton, a heavy compressed grotesque with flyposter weight. Body and UI: Archivo, a squarer grotesque. Contrast is weight and width, not serif versus sans. Reflex picks (Bebas Neue, Barlow Condensed) were rejected.
